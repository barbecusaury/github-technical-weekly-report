# GitHub技术周报

这个 skill 用于生成、维护和发布单文件版 GitHub 技术周报 HTML。它适合处理 GitHub 一周热榜、一个月热榜和飙升榜这类排行榜页面，并要求页面可以直接打开，不依赖本地构建流程。

## 能做什么

- 生成或更新克制的技术编辑类排行榜页面。
- 维护简体中文、繁体中文和英语三种语言切换。
- 本地化页面标题、分区说明、榜单摘要、弹窗项目介绍、作用说明和使用建议。
- 保留弹窗的关闭按钮、遮罩关闭、Esc 关闭和键盘可访问性。
- 验证 HTML 文件存在、内联脚本可解析、语言按钮存在、榜单排序连续、项目介绍走本地化路径。
- 在用户要求时把报告或 skill 发布到 GitHub。

## 使用方式

让 Codex 使用 `$github-technical-weekly-report`，并提供目标 HTML 文件或说明要新生成一份周报。更新后应运行本地验证脚本；如果要上传 GitHub，应确认目标仓库、分支和文件路径，再提交或网页上传。
